# AI-Assisted Empirical Research with Claude Code

Kursmaterial für den GGS-Workshop im Oktober 2026. Hier liegt alles, was ihr für den Kurs
herunterladen müsst.

## Herunterladen

Klickt oben auf **Code** und dann auf **Download ZIP**. Entpackt die ZIP-Datei. Der entpackte
Ordner ist euer Kursordner.

## Inhalt

- `syllabus.pdf`: der Syllabus des Workshops.
- `launcher/`: die Startdatei, mit der Claude Code über das Budget der Universität läuft.
  `claude-jlu.bat` ist für Windows, `claude-jlu.command` für den Mac. Was ihr damit macht, zeigen
  wir am ersten Kurstag.
- `slides/`: die Folien. Sie kommen im Lauf des Kurses dazu.
